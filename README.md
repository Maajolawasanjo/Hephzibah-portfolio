# Hephie Creatives — Portfolio

Professional portfolio for **Hephzibah Uzorndu**, Brand Identity Designer
& Visual Storyteller and founder of **Hephie Creatives**, Lagos, Nigeria.

## Current milestone — Phase 06 (Selected Work)

The homepage has an expressive editorial hero, confirmed service summary,
and a responsive, data-driven Selected Work gallery.

**The gallery is not populated yet.** Real project artwork and case-study
details must be verified with Hephzibah before publication. It currently
renders an honest "In curation" state. The site is still in development
and indexing is intentionally disabled.

## Approved design

- Modern Editorial Minimalism and expressive typography
- Burgundy `#66001F` and Cream `#FEFCEF`
- Display: **Alro by Artyway** — licensed webfont files still needed
- Body: **DM Sans** (temporary display fallback)

## Technology and local checks

Next.js App Router, React, TypeScript, Tailwind CSS v4.

Use Node.js 22:

    npm install
    npm run dev
    npm run lint
    npm run typecheck
    npm run build

The repo still needs a committed package-lock.json from a connected npm
environment. CI currently uses npm install; switch to npm ci after the
lockfile is generated and committed.
